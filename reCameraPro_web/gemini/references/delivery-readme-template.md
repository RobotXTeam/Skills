## 写作要点

**要写的**

- 第一屏就给「双击打开哪个文件」
- 操作路径写清到能照着点（页面 → 标签 → 区块 → 按钮）
- 可点的清单，一条一行
- 「要跟研发说明的三点」——这是产品最需要传达的信息
- 设备端接口是否已实现（**不要含糊**）

**不要写的**

- 安装步骤、命令行、服务启动（演示是双击打开的，不需要这些）
- 单元测试、构建命令、部署流程
- 代码结构讲解（那些放 `files/` 里，研发自己看）
- 大段技术原理（产品不关心）
